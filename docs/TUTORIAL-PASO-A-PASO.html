Catálogo de Carreras UASD · tutorial en NetBeans

Construir el programa de principio a fin, en NetBeans

Los pasos tal como se hacen dentro de NetBeans: instalarlo, crear el proyecto, crear los paquetes y las clases desde los menús, agregar el driver con Add JAR/Folder y ejecutar con el botón verde. Cada paso dice qué hacer, el código que va en cada archivo y cómo comprobar que quedó bien.

Qué está verificado y qué no

Se verificó en Apache NetBeans 31 con JDK 21: crear el proyecto con el asistente, ver los paquetes en Source Packages, agregar el JAR en Libraries, marcar la clase principal, y ejecutar con el botón verde (el programa abrió y consultó la base). Los menús de crear paquetes, clases e interfaces, y el de cambiar la versión de Java, son los estándar de NetBeans, pero no los verifiqué en la versión 31: si el nombre de un menú no coincide, busca el equivalente. Los comandos de PowerShell, SQL Server Express y los scripts sí se probaron en este equipo.

Hay otra versión de este tutorial que usa solo la terminal, sin NetBeans: TUTORIAL-PASO-A-PASO-TERMINAL.html, en la misma carpeta.

Fase 1 · Preparar la computadora

Paso 1Instalar el JDK (Java)

NetBeans necesita un JDK para funcionar, y el programa también. Hace falta el 21 o uno superior para NetBeans 31; el proyecto se configurará después para Java 11.

winget install --id EclipseAdoptium.Temurin.21.JDK

Si no tienes winget, descarga Eclipse Temurin 21 desde adoptium.net. Después cierra la terminal y abre una nueva.

Comprobar

Escribe java -version. Debe decir openjdk version "21...".

Paso 2Descargar NetBeans

NetBeans es el programa donde se escribe y ejecuta el código Java. La versión más reciente es la 31 (agosto de 2026). Apache ya no publica versiones LTS, así que la más reciente es la recomendada. Se descarga el archivo oficial, que no necesita instalación: se extrae y se abre.

mkdir C:\Users\TU-USUARIO\NetBeans
cd C:\Users\TU-USUARIO\NetBeans
Invoke-WebRequest -Uri https://dlcdn.apache.org/netbeans/netbeans/31/netbeans-31-bin.zip -OutFile netbeans-31-bin.zip
Invoke-WebRequest -Uri https://downloads.apache.org/netbeans/netbeans/31/netbeans-31-bin.zip.sha512 -OutFile netbeans-31-bin.zip.sha512

Pesa unos 497 MB y tardó unos 6 minutos. Cambia TU-USUARIO por tu usuario de Windows.

Verifica que el archivo no esté dañado, comparando su huella SHA-512 con la que publica Apache, y extráelo:

(Get-FileHash netbeans-31-bin.zip -Algorithm SHA512).Hash.ToLower() -eq ((Get-Content netbeans-31-bin.zip.sha512 -Raw).Trim() -split '\s+')[0].ToLower()
Expand-Archive netbeans-31-bin.zip -DestinationPath .
Comprobar

La primera línea debe imprimir True. Después de extraer existe netbeans\bin\netbeans64.exe.

Paso 3Tener SQL Server encendido

El programa se conecta a SQL Server por TCP, en el puerto 1433. Se instala SQL Server Express, como en el blog de la clase.

  1. Descarga el instalador de SQL Server Express (gratis) desde microsoft.com/sql-server/sql-server-downloads. Si tu Windows está en español, descarga el instalador en español: uno en inglés se detiene con el error "This SQL Server setup media does not support the language of the OS".
  2. Ejecútalo y elige Custom. Cuando termine de descargar se abre el SQL Server Installation Center. Elige New SQL Server standalone installation.
  3. En la pantalla Azure Extension for SQL Server, quita la casilla. No hace falta.
  4. En Feature Selection deja solo Database Engine Services. En Instance Configuration deja la instancia con nombre SQLEXPRESS.
  5. En Database Engine Configuration elige Mixed Mode (autenticación de SQL Server y de Windows). Escribe la clave de sa: Catalogo_UASD_2026, en los dos campos. Pulsa Add Current User para que tu usuario de Windows también sea administrador.
  6. Pulsa Next hasta Install. Al final debe decir Your SQL Server 2022 installation completed successfully.

Activar TCP/IP en el puerto 1433

Por defecto SQL Server no acepta conexiones por TCP, y el driver de Java solo sabe conectarse así. Se activa con el SQL Server Configuration Manager:

  1. Pulsa Windows + R, escribe SQLServerManager16.msc y acepta el permiso de administrador.
  2. A la izquierda, abre SQL Server Network Configuration y haz clic en Protocols for SQLEXPRESS.
  3. Doble clic en TCP/IP. En la pestaña Protocol, pon Enabled = Yes.
  4. En la pestaña IP Addresses, baja hasta IPAll. En TCP Dynamic Ports borra lo que haya y déjalo vacío. En TCP Port escribe 1433. Pulsa OK.
  5. Entra en SQL Server Services, clic derecho sobre SQL Server (SQLEXPRESS) y Restart.

Si otro programa ocupa el puerto 1433, SQL Server no puede usarlo y el reinicio no basta: cierra ese programa y reinicia el servicio otra vez. La clave y el servidor están escritos en ConexionBD.java (paso 20); con estos pasos no hay que cambiarlos.

Comprobar

Desde tu PC, con sqlcmd:

sqlcmd -S localhost,1433 -U sa -P Catalogo_UASD_2026 -C -Q "SELECT @@VERSION"

Debe imprimir una línea que empieza con Microsoft SQL Server.

Ver los datos con SQL Server Management Studio (SSMS)

SSMS es solo la ventana para ver y consultar la base; el servidor es SQL Server Express. Para conectarte: Server name localhost,1433, Authentication SQL Server Authentication, Login sa y la clave Catalogo_UASD_2026. Si sale un error de certificado, en Options >> Connection Properties marca Trust server certificate. La base CatalogoUASD aparece después de ejecutar el programa por primera vez: Databases → CatalogoUASD → Tables, clic derecho sobre dbo.carrera y Select Top 1000 Rows.

Fase 2 · El proyecto en NetBeans

Paso 4Abrir NetBeans

Haz doble clic en netbeans\bin\netbeans64.exe. Si te pide un JDK o no arranca, ábrelo desde PowerShell indicándole el que instalaste:

& "C:\Users\TU-USUARIO\NetBeans\netbeans\bin\netbeans64.exe" --jdkhome "C:\Program Files\Eclipse Adoptium\jdk-21.0.13.9-hotspot"
Comprobar

Se abre la ventana Apache NetBeans IDE 31, con la barra de menús File, Edit, View, Navigate, Source, Refactor, Run, Debug, Profile, Team, Tools, Window, Help.

Paso 5Crear el proyecto

  1. File → New Project (o Ctrl + Shift + N).
  2. En Categories elige Java with Ant. Cuidado: elige exactamente esa categoría.
  3. A la derecha elige Java Application y pulsa Next.
  4. Project Name: catalogo-carreras-uasd. Project Location: la carpeta donde quieras guardarlo, por ejemplo el Escritorio.
  5. En Create Main Class escribe uasd.catalogo.Main. Así NetBeans crea el paquete uasd.catalogo con una clase Main y la marca como la clase principal.
  6. Pulsa Finish.

En los videos de la clase el proyecto se crea igual, con el asistente de NetBeans. Esta ruta (Java Application) es la estándar; la que sí se verificó en la versión 31 es la de Java Project with Existing Sources, que se usa cuando el código ya existe.

Comprobar

En la ventana Projects (a la izquierda) aparece catalogo-carreras-uasd, con Source Packages (que contiene uasd.catalogo) y Libraries (que dice JDK 21 (Default)).

Paso 6Poner el proyecto en Java 11

NetBeans configura el proyecto con la versión de tu JDK, que es la 21. Si un compañero tiene el JDK 17 o el 11, el proyecto no compilaría. Se baja a la 11, que es lo mínimo que acepta el driver, y así sirve en cualquier computadora.

  1. Clic derecho sobre el proyecto, Properties.
  2. Categoría Sources, y en Source/Binary Format elige 11.
  3. Pulsa OK.
Comprobar

En la pestaña Files, abre nbproject\project.properties: deben decir javac.source=11 y javac.target=11.

Paso 7Crear las carpetas y los paquetes

Primero, dos carpetas en la raíz del proyecto, una para los scripts SQL y otra para el driver. Con PowerShell, desde la carpeta del proyecto:

mkdir sql, lib, docs, docs\capturas

Después, los cuatro paquetes de Java. En Source Packages, clic derecho → New → Java Package, y crea uno por uno:

uasd.catalogo.modelo
uasd.catalogo.dao
uasd.catalogo.conexion
uasd.catalogo.formularios

Cada punto del nombre de un paquete es una carpeta: uasd.catalogo.modelo es src\uasd\catalogo\modelo.

Comprobar

En Source Packages deben verse cinco paquetes: uasd.catalogo, uasd.catalogo.conexion, uasd.catalogo.dao, uasd.catalogo.formularios y uasd.catalogo.modelo.

Fase 3 · La base de datos

Paso 8Crear la base de datos

Una base de datos es el contenedor de las tablas. Esta se llamará CatalogoUASD. Desde la carpeta del proyecto:

sqlcmd -S localhost,1433 -U sa -P Catalogo_UASD_2026 -C -Q "CREATE DATABASE CatalogoUASD"

Este paso y los dos siguientes se pueden hacer a mano, como aquí, para entender qué se crea. El programa final también los hace solo la primera vez que se ejecuta (InicializadorBD, paso 23), y si encuentra todo ya creado no repite nada.

Comprobar

sqlcmd -S localhost,1433 -U sa -P Catalogo_UASD_2026 -C -Q "SELECT name FROM sys.databases" debe listar CatalogoUASD.

Paso 9Crear las tablas

La UASD se organiza en tres niveles: una facultad tiene varias escuelas, y una escuela administra varias carreras. Son tres tablas, unidas por claves foráneas.

Crea el archivo sql\01_esquema.sql en la carpeta sql (con el Bloc de notas, o en la pestaña Files de NetBeans) y pega este código:

sql/01_esquema.sql

CREATE TABLE facultad (
    id INT IDENTITY(1,1) NOT NULL,
    nombre NVARCHAR(100) NOT NULL,
    CONSTRAINT PK_facultad PRIMARY KEY (id),
    CONSTRAINT UQ_facultad_nombre UNIQUE (nombre)
);
GO

CREATE TABLE escuela (
    id INT IDENTITY(1,1) NOT NULL,
    nombre NVARCHAR(150) NOT NULL,
    facultad_id INT NOT NULL,
    CONSTRAINT PK_escuela PRIMARY KEY (id),
    CONSTRAINT UQ_escuela_nombre UNIQUE (nombre),
    CONSTRAINT FK_escuela_facultad FOREIGN KEY (facultad_id) REFERENCES facultad (id)
);
GO

CREATE TABLE carrera (
    id INT IDENTITY(1,1) NOT NULL,
    nombre NVARCHAR(200) NOT NULL,
    nivel NVARCHAR(10) NOT NULL,
    proyectada BIT NOT NULL DEFAULT 0,
    escuela_id INT NOT NULL,
    CONSTRAINT PK_carrera PRIMARY KEY (id),
    CONSTRAINT CK_carrera_nivel CHECK (nivel IN (N'Técnico', N'Grado')),
    CONSTRAINT FK_carrera_escuela FOREIGN KEY (escuela_id) REFERENCES escuela (id)
);
GO
PiezaQué hace
IDENTITY(1,1)Genera el id solo, empezando en 1
PRIMARY KEYIdentifica cada fila de forma única
UNIQUEImpide repetir un nombre
FOREIGN KEY ... REFERENCESObliga a que facultad_id sea el id de una facultad que existe
CHECKImpide que el nivel sea algo distinto de Técnico o Grado
GOSepara bloques. No es SQL: lo entienden las herramientas de SQL Server
sqlcmd -S localhost,1433 -U sa -P Catalogo_UASD_2026 -C -d CatalogoUASD -f 65001 -i sql\01_esquema.sql

-d elige la base, -i el archivo, y -f 65001 le dice que el archivo está en UTF-8, para que las tildes se guarden bien. Si guardas el archivo desde NetBeans, ya sale en UTF-8.

Comprobar

sqlcmd -S localhost,1433 -U sa -P Catalogo_UASD_2026 -C -d CatalogoUASD -Q "SELECT name FROM sys.tables" debe listar facultad, escuela y carrera.

Paso 12Descargar el driver a la carpeta lib

Para que Java hable con SQL Server hace falta el driver. Las librerías de Java se distribuyen en archivos JAR: un archivo comprimido, parecido a un .zip, con clases ya compiladas. El del driver se llama mssql-jdbc-12.8.1.jre11.jar y pesa 1,4 MB.

Es importante que el archivo quede dentro de la carpeta del proyecto. Así NetBeans guarda una ruta relativa y el proyecto funciona en otras computadoras.

Paso 14La clase padre: EntidadCatalogo

Es la clase de la que heredan todas las demás. Guarda lo que tienen en común una facultad y una carrera: un id y un nombre. Crea la clase EntidadCatalogo en el paquete uasd.catalogo.modelo:

src/uasd/catalogo/modelo/EntidadCatalogo.java

package uasd.catalogo.modelo;

public abstract class EntidadCatalogo {
    private int id;
    private String nombre;

    protected EntidadCatalogo(int id, String nombre) {
        this.id = id;
        this.nombre = nombre;
    }

    public int getId() {
        return id;
    }

    public void setId(int id) {
        this.id = id;
    }

    public String getNombre() {
        return nombre;
    }

    public void setNombre(String nombre) {
        this.nombre = nombre;
    }

    public abstract String getTipo();

    public final String describir() {
        return getTipo() + ": " + nombre;
    }

    @Override
    public String toString() {
        return nombre;
    }

    @Override
    public boolean equals(Object otro) {
        if (this == otro) {
            return true;
        }
        if (otro == null || getClass() != otro.getClass()) {
            return false;
        }
        EntidadCatalogo otraEntidad = (EntidadCatalogo) otro;
        return id == otraEntidad.id;
    }

    @Override
    public int hashCode() {
        return Integer.hashCode(id);
    }
}
  • abstract class: no se puede crear con new. Existen facultades y carreras, pero no una "entidad" a secas.
  • private con getters y setters: encapsulamiento. Los datos solo se tocan por los métodos.
  • protected en el constructor: solo lo pueden llamar las clases hijas.
  • public abstract String getTipo(): una obligación para las hijas. Cada una debe decir qué es.
  • public final String describir(): arma "tipo: nombre". Es final, así que ninguna hija puede cambiarlo.
  • toString, equals y hashCode: métodos de Object que se redefinen con @Override.

Paso 20ConexionBD: la clase que abre la conexión

Crea la clase ConexionBD en el paquete uasd.catalogo.conexion. Es la única clase que sabe cómo conectarse a SQL Server. Los datos de conexión son constantes al inicio: si tu servidor, usuario o clave son otros, solo se cambian aquí.

src/uasd/catalogo/conexion/ConexionBD.java

package uasd.catalogo.conexion;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;

public class ConexionBD {
    private static final String DRIVER = "com.microsoft.sqlserver.jdbc.SQLServerDriver";
    private static final String SERVIDOR = "jdbc:sqlserver://localhost:1433;encrypt=true;trustServerCertificate=true";
    private static final String BASE = "CatalogoUASD";
    private static final String USUARIO = "sa";
    private static final String CLAVE = "Catalogo_UASD_2026";

    public static String getBase() {
        return BASE;
    }

    public static Connection conectarServidor() throws SQLException {
        cargarDriver();
        return DriverManager.getConnection(SERVIDOR, USUARIO, CLAVE);
    }

    public static Connection conectar() throws SQLException {
        cargarDriver();
        return DriverManager.getConnection(SERVIDOR + ";databaseName=" + BASE, USUARIO, CLAVE);
    }

    private static void cargarDriver() throws SQLException {
        try {
            Class.forName(DRIVER);
        } catch (ClassNotFoundException e) {
            throw new SQLException("No se encontró el driver de SQL Server", e);
        }
    }
}

Cómo se conecta, en cuatro pasos: (1) se carga el driver; (2) DriverManager.getConnection(dirección, usuario, clave) llama por TCP a localhost:1433; (3) SQL Server Express, que escucha en ese puerto, recibe la llamada; (4) SQL Server revisa el usuario y la clave, y devuelve una conexión abierta.

Si usaste la opción B del paso 3, cambia aquí USUARIO y CLAVE por los de tu servidor. Si tu instancia tiene nombre, por ejemplo SQLEXPRESS, cambia SERVIDOR a jdbc:sqlserver://localhost\\SQLEXPRESS;encrypt=true;trustServerCertificate=true.

package uasd.catalogo.dao;

import java.sql.Connection;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.sql.Statement;
import java.util.ArrayList;
import java.util.List;
import uasd.catalogo.conexion.ConexionBD;
import uasd.catalogo.modelo.Facultad;

public class FacultadDAOJdbc implements FacultadDAO {

    @Override
    public List<Facultad> listarTodas() throws SQLException {
        List<Facultad> facultades = new ArrayList<>();
        Connection conexion = ConexionBD.conectar();
        try {
            Statement sentencia = conexion.createStatement();
            ResultSet resultado = sentencia.executeQuery("SELECT id, nombre FROM facultad ORDER BY nombre");

            while (resultado.next()) {
                int id = resultado.getInt("id");
                String nombre = resultado.getString("nombre");
                facultades.add(new Facultad(id, nombre));
            }
            resultado.close();
            sentencia.close();
        } finally {
            conexion.close();
        }
        return facultades;
    }
}

src/uasd/catalogo/dao/CarreraDAOJdbc.java

package uasd.catalogo.dao;

import java.sql.Connection;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.sql.Statement;
import java.util.ArrayList;
import java.util.List;
import uasd.catalogo.conexion.ConexionBD;
import uasd.catalogo.modelo.Carrera;
import uasd.catalogo.modelo.CarreraGrado;
import uasd.catalogo.modelo.CarreraTecnica;
import uasd.catalogo.modelo.NivelCarrera;

public class CarreraDAOJdbc implements CarreraDAO {

    @Override
    public List<Carrera> listarPorFacultad(int facultadId) throws SQLException {
        List<Carrera> carreras = new ArrayList<>();

        String sql = "SELECT c.id, c.nombre, c.nivel, c.proyectada, e.nombre AS escuela "
                + "FROM carrera c "
                + "JOIN escuela e ON e.id = c.escuela_id "
                + "WHERE e.facultad_id = " + facultadId + " "
                + "ORDER BY e.nombre, c.nivel DESC, c.nombre";

        Connection conexion = ConexionBD.conectar();
        try {
            Statement sentencia = conexion.createStatement();
            ResultSet resultado = sentencia.executeQuery(sql);

            while (resultado.next()) {
                int id = resultado.getInt("id");
                String nombre = resultado.getString("nombre");
                String escuela = resultado.getString("escuela");
                boolean proyectada = resultado.getBoolean("proyectada");
                String nivel = resultado.getString("nivel");

                Carrera carrera;
                if (nivel.equals(NivelCarrera.TECNICO)) {
                    carrera = new CarreraTecnica(id, nombre, escuela, proyectada);
                } else {
                    carrera = new CarreraGrado(id, nombre, escuela, proyectada);
                }
                carreras.add(carrera);
            }
            resultado.close();
            sentencia.close();
        } finally {
            conexion.close();
        }
        return carreras;
    }
}

En CarreraDAOJdbc la consulta une la carrera con su escuela (JOIN) y se queda con las de la facultad pedida. Al leer cada fila decide qué clase crear: si el nivel es "Técnico" crea una CarreraTecnica, y si no, una CarreraGrado. Las dos se guardan en la misma lista de tipo Carrera.

package uasd.catalogo.conexion;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.File;
import java.io.FileInputStream;
import java.io.InputStreamReader;
import java.nio.charset.StandardCharsets;
import java.sql.Connection;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.sql.Statement;
import java.util.ArrayList;
import java.util.List;

public class InicializadorBD {
    private static final String[] SCRIPTS = {"01_esquema.sql", "02_datos.sql"};

    public static void preparar() throws SQLException, IOException {
        crearBaseSiNoExiste();
        crearTablasSiNoExisten();
    }

    private static void crearBaseSiNoExiste() throws SQLException {
        String base = ConexionBD.getBase();
        Connection conexion = ConexionBD.conectarServidor();
        try {
            Statement sentencia = conexion.createStatement();
            ResultSet resultado = sentencia.executeQuery("SELECT DB_ID('" + base + "')");
            resultado.next();
            resultado.getInt(1);
            boolean existe = !resultado.wasNull();
            resultado.close();

            if (!existe) {
                sentencia.executeUpdate("CREATE DATABASE " + base);
            }
            sentencia.close();
        } finally {
            conexion.close();
        }
    }

    private static void crearTablasSiNoExisten() throws SQLException, IOException {
        Connection conexion = ConexionBD.conectar();
        try {
            Statement sentencia = conexion.createStatement();
            ResultSet resultado = sentencia.executeQuery("SELECT OBJECT_ID('dbo.carrera', 'U')");
            resultado.next();
            resultado.getInt(1);
            boolean existe = !resultado.wasNull();
            resultado.close();

            if (!existe) {
                for (String script : SCRIPTS) {
                    for (String bloque : leerBloques(script)) {
                        sentencia.execute(bloque);
                    }
                }
            }
            sentencia.close();
        } finally {
            conexion.close();
        }
    }

    private static List<String> leerBloques(String nombreArchivo) throws IOException {
        List<String> bloques = new ArrayList<>();
        StringBuilder actual = new StringBuilder();

        File archivo = new File("sql", nombreArchivo);
        if (!archivo.exists()) {
            throw new IOException("No se encontró " + archivo.getPath() + ". Ejecuta el programa desde la carpeta del proyecto.");
        }

        BufferedReader lector = new BufferedReader(new InputStreamReader(new FileInputStream(archivo), StandardCharsets.UTF_8));
        try {
            String linea;
            while ((linea = lector.readLine()) != null) {
                if (linea.trim().equalsIgnoreCase("GO")) {
                    if (!actual.toString().isBlank()) {
                        bloques.add(actual.toString());
                    }
                    actual = new StringBuilder();
                } else {
                    actual.append(linea).append("\n");
                }
            }
        } finally {
            lector.close();
        }
        if (!actual.toString().isBlank()) {
            bloques.add(actual.toString());
        }
        return bloques;
    }
}
  • crearBaseSiNoExiste() se conecta al servidor (sin base, porque quizá aún no existe) y pregunta con DB_ID. Si da vacío, ejecuta CREATE DATABASE.
  • crearTablasSiNoExisten() pregunta con OBJECT_ID si existe la tabla carrera. Si no, ejecuta los dos scripts.
  • leerBloques() lee cada script de la carpeta sql y lo corta en cada línea GO, porque JDBC no entiende GO. Como busca la carpeta sql con una ruta relativa, el programa debe ejecutarse desde la carpeta del proyecto; NetBeans lo hace así.

Crea un repositorio vacío en GitHub, copia su dirección y, desde la carpeta del proyecto, en una terminal:

git init
git add .
git commit -m "Catálogo de carreras UASD"
git branch -M main
git remote add origin <URL-DE-TU-REPOSITORIO>
git push -u origin main
Comprobar

Abre el repositorio en GitHub y confirma que se ven README.md, build.xml, nbproject, lib, sql, src y docs, y que no aparecen las carpetas build ni dist. Pide al profesor acceso, o deja el repositorio público. Después, la prueba final: clónalo en otra carpeta, ábrelo en NetBeans con File → Open Project y pulsa el botón verde.

Si no tienes NetBeans: la terminal

El proyecto también se compila y ejecuta sin NetBeans, con los archivos compilar.bat y ejecutar.bat. Desde la carpeta del proyecto:

.\ejecutar.bat

Ese archivo compila el programa con javac y lo arranca con java -cp ..., usando el JAR de lib. NetBeans y compilar.bat escriben en la misma carpeta de salida (build\classes), así que no los uses a la vez. Los dos archivos y su explicación están en TUTORIAL-PASO-A-PASO-TERMINAL.html.
