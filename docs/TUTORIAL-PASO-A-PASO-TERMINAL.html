Cómo usar este tutorial

Sigue los pasos en orden, sin saltarte ninguno. Cada archivo se muestra completo para que lo copies tal cual. Los comandos son de Windows (PowerShell) y se escriben en una terminal abierta en la carpeta del proyecto. Los pasos con SQL Server, los scripts, la descarga del JAR, la compilación y la ejecución se probaron en este equipo. Los pasos de NetBeans se probaron en Apache NetBeans 31 con JDK 21. No se probó SQL Server Express con el Configuration Manager (es el procedimiento del blog de la clase).

Fase 1 · Preparar la computadora

Paso 1Instalar el JDK (Java)

Sin el JDK no se puede compilar ni ejecutar Java. Trae el compilador (javac) y la máquina virtual (java). Hace falta la versión 17 o una superior; aquí se usó la 21.

winget install --id EclipseAdoptium.Temurin.21.JDK

Si no tienes winget, descarga Eclipse Temurin 21 desde adoptium.net. Después cierra la terminal y abre una nueva, para que reconozca Java.

Comprobar

Escribe java -version. Debe decir openjdk version "21...". También sirve javac -version.

Paso 2Tener SQL Server encendido

El programa necesita un SQL Server al que conectarse por TCP, en el puerto 1433. Se instala SQL Server Express, como en el blog de la clase.

  1. Descarga SQL Server Express desde microsoft.com/sql-server/sql-server-downloads. Si tu Windows está en español, descarga el instalador en español: uno en inglés falla con el error "does not support the language of the OS".
  2. Ejecútalo, elige Custom y luego New SQL Server standalone installation. Quita la casilla de Azure Extension; deja solo Database Engine Services y la instancia SQLEXPRESS.
  3. En Database Engine Configuration elige Mixed Mode y ponle a sa la clave Catalogo_UASD_2026. Pulsa Add Current User.
  4. Abre el SQL Server Configuration Manager (Windows + R, SQLServerManager16.msc). En SQL Server Network Configuration → Protocols for SQLEXPRESS habilita TCP/IP. En la pestaña IP Addresses, en IPAll, deja vacío TCP Dynamic Ports y pon TCP Port = 1433.
  5. En SQL Server Services, clic derecho sobre SQL Server (SQLEXPRESS) y Restart. Si otro programa ocupa el puerto 1433, ciérralo antes.

La clave y el servidor están en un solo archivo, ConexionBD.java (paso 16). Con sa y Catalogo_UASD_2026 no hay que cambiar nada.

Comprobar

Con sqlcmd, que viene con las herramientas de SQL Server:

sqlcmd -S localhost,1433 -U sa -P Catalogo_UASD_2026 -C -Q "SELECT @@VERSION"

Debe imprimir una línea que empieza con Microsoft SQL Server. Si no tienes sqlcmd, comprueba la conexión con SQL Server Management Studio o con la extensión SQL Server (mssql) de VS Code.

Fase 2 · La base de datos

Paso 3Crear las carpetas del proyecto

Todo el proyecto vive en una carpeta. El código Java va dentro de src, que es la carpeta que usan los proyectos de NetBeans, y cada punto del nombre de un paquete es una subcarpeta: uasd.catalogo.modelo es src\uasd\catalogo\modelo.

mkdir catalogo-carreras-uasd
cd catalogo-carreras-uasd
mkdir sql, lib, docs, docs\capturas
mkdir src\uasd\catalogo\modelo, src\uasd\catalogo\dao, src\uasd\catalogo\conexion, src\uasd\catalogo\formularios

Comprobar

Escribe tree /F o abre la carpeta en el explorador: deben existir las carpetas de la estructura, todas vacías.

Paso 4Crear la base de datos

Una base de datos es el contenedor de las tablas. Esta se llamará CatalogoUASD.

sqlcmd -S localhost,1433 -U sa -P Catalogo_UASD_2026 -C -Q "CREATE DATABASE CatalogoUASD"

Este paso y los dos siguientes se pueden hacer a mano, como aquí, para entender qué se está creando. El programa final también los hace solo la primera vez que se ejecuta (clase InicializadorBD, paso 19), y si encuentra todo ya creado no repite nada.

Comprobar

Sin errores en la terminal. Con sqlcmd -S localhost,1433 -U sa -P Catalogo_UASD_2026 -C -Q "SELECT name FROM sys.databases" debe aparecer CatalogoUASD en la lista.

Paso 5Crear las tablas

La UASD se organiza en tres niveles: una facultad tiene varias escuelas, y una escuela administra varias carreras. Son tres tablas, unidas por claves foráneas.

Crea el archivo sql\01_esquema.sql y pega este código:

sql/01_esquema.sql

CREATE TABLE facultad (
    id INT IDENTITY(1,1) NOT NULL,
    nombre NVARCHAR(100) NOT NULL,
    CONSTRAINT PK_facultad PRIMARY KEY (id),
    CONSTRAINT UQ_facultad_nombre UNIQUE (nombre)
);
GO

CREATE TABLE escuela (
    id INT IDENTITY(1,1) NOT NULL,
    nombre NVARCHAR(150) NOT NULL,
    facultad_id INT NOT NULL,
    CONSTRAINT PK_escuela PRIMARY KEY (id),
    CONSTRAINT UQ_escuela_nombre UNIQUE (nombre),
    CONSTRAINT FK_escuela_facultad FOREIGN KEY (facultad_id) REFERENCES facultad (id)
);
GO

CREATE TABLE carrera (
    id INT IDENTITY(1,1) NOT NULL,
    nombre NVARCHAR(200) NOT NULL,
    nivel NVARCHAR(10) NOT NULL,
    proyectada BIT NOT NULL DEFAULT 0,
    escuela_id INT NOT NULL,
    CONSTRAINT PK_carrera PRIMARY KEY (id),
    CONSTRAINT CK_carrera_nivel CHECK (nivel IN (N'Técnico', N'Grado')),
    CONSTRAINT FK_carrera_escuela FOREIGN KEY (escuela_id) REFERENCES escuela (id)
);
GO
PiezaQué hace
IDENTITY(1,1)Genera el id solo, empezando en 1
PRIMARY KEYIdentifica cada fila de forma única
UNIQUEImpide repetir un nombre
FOREIGN KEY ... REFERENCESObliga a que facultad_id sea el id de una facultad que existe
CHECKImpide que el nivel sea algo distinto de Técnico o Grado
GOSepara bloques. No es SQL: lo entienden las herramientas de SQL Server

Ejecútalo:

sqlcmd -S localhost,1433 -U sa -P Catalogo_UASD_2026 -C -d CatalogoUASD -f 65001 -i sql\01_esquema.sql

-d elige la base, -i el archivo, y -f 65001 le dice que el archivo está en UTF-8, para que las tildes se guarden bien.

Comprobar

Sin errores. sqlcmd -S localhost,1433 -U sa -P Catalogo_UASD_2026 -C -d CatalogoUASD -Q "SELECT name FROM sys.tables" debe listar facultad, escuela y carrera.

Paso 10La clase padre: EntidadCatalogo

package uasd.catalogo.modelo;

public abstract class EntidadCatalogo {
    private int id;
    private String nombre;

    protected EntidadCatalogo(int id, String nombre) {
        this.id = id;
        this.nombre = nombre;
    }

    public int getId() {
        return id;
    }

    public void setId(int id) {
        this.id = id;
    }

    public String getNombre() {
        return nombre;
    }

    public void setNombre(String nombre) {
        this.nombre = nombre;
    }

    public abstract String getTipo();

    public final String describir() {
        return getTipo() + ": " + nombre;
    }

    @Override
    public String toString() {
        return nombre;
    }

    @Override
    public boolean equals(Object otro) {
        if (this == otro) {
            return true;
        }
        if (otro == null || getClass() != otro.getClass()) {
            return false;
        }
        EntidadCatalogo otraEntidad = (EntidadCatalogo) otro;
        return id == otraEntidad.id;
    }

    @Override
    public int hashCode() {
        return Integer.hashCode(id);
    }
}
  • abstract class: no se puede crear con new. Existen facultades y carreras, pero no una "entidad" a secas.
  • private con getters y setters: encapsulamiento. Los datos solo se tocan por los métodos.
  • protected en el constructor: solo lo pueden llamar las clases hijas.
  • public abstract String getTipo(): una obligación para las hijas. Cada una debe decir qué es.
  • public final String describir(): arma "tipo: nombre". Es final, así que ninguna hija puede cambiarlo.
  • toString, equals y hashCode: métodos de Object que se redefinen con @Override.

    private static final String BASE = "CatalogoUASD";
    private static final String USUARIO = "sa";
    private static final String CLAVE = "Catalogo_UASD_2026";

        return BASE;

        cargarDriver();
        return DriverManager.getConnection(SERVIDOR, USUARIO, CLAVE);
    }

        cargarDriver();
        return DriverManager.getConnection(SERVIDOR + ";databaseName=" + BASE, USUARIO, CLAVE);

        try {
            Class.forName(DRIVER);
        } catch (ClassNotFoundException e) {
            throw new SQLException("No se encontró el driver de SQL Server", e);
        }
    }
}

        try {
            Statement sentencia = conexion.createStatement();

                String nombre = resultado.getString("nombre");

package uasd.catalogo.dao;

import java.sql.Connection;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.sql.Statement;
import java.util.ArrayList;
import java.util.List;
import uasd.catalogo.conexion.ConexionBD;
import uasd.catalogo.modelo.Carrera;
import uasd.catalogo.modelo.CarreraGrado;
import uasd.catalogo.modelo.CarreraTecnica;
import uasd.catalogo.modelo.NivelCarrera;

public class CarreraDAOJdbc implements CarreraDAO {

    @Override
    public List<Carrera> listarPorFacultad(int facultadId) throws SQLException {
        List<Carrera> carreras = new ArrayList<>();

        String sql = "SELECT c.id, c.nombre, c.nivel, c.proyectada, e.nombre AS escuela "
                + "FROM carrera c "
                + "JOIN escuela e ON e.id = c.escuela_id "
                + "WHERE e.facultad_id = " + facultadId + " "
                + "ORDER BY e.nombre, c.nivel DESC, c.nombre";

        Connection conexion = ConexionBD.conectar();
        try {
            Statement sentencia = conexion.createStatement();
            ResultSet resultado = sentencia.executeQuery(sql);

            while (resultado.next()) {
                int id = resultado.getInt("id");
                String nombre = resultado.getString("nombre");
                String escuela = resultado.getString("escuela");
                boolean proyectada = resultado.getBoolean("proyectada");
                String nivel = resultado.getString("nivel");

                Carrera carrera;
                if (nivel.equals(NivelCarrera.TECNICO)) {
                    carrera = new CarreraTecnica(id, nombre, escuela, proyectada);
                } else {
                    carrera = new CarreraGrado(id, nombre, escuela, proyectada);
                }
                carreras.add(carrera);
            }
            resultado.close();
            sentencia.close();
        } finally {
            conexion.close();
        }
        return carreras;
    }
}

En CarreraDAOJdbc la consulta une la carrera con su escuela (JOIN) y se queda con las de la facultad pedida. Al leer cada fila decide qué clase crear: si el nivel es "Técnico" crea una CarreraTecnica, y si no, una CarreraGrado. Las dos se guardan en la misma lista de tipo Carrera.

    private static void crearTablasSiNoExisten() throws SQLException, IOException {
        Connection conexion = ConexionBD.conectar();
        try {
            Statement sentencia = conexion.createStatement();
            ResultSet resultado = sentencia.executeQuery("SELECT OBJECT_ID('dbo.carrera', 'U')");
            resultado.next();
            resultado.getInt(1);
            boolean existe = !resultado.wasNull();
            resultado.close();

            if (!existe) {
                for (String script : SCRIPTS) {
                    for (String bloque : leerBloques(script)) {
                        sentencia.execute(bloque);
                    }
                }
            }
            sentencia.close();
        } finally {
            conexion.close();
        }
    }

    private static List<String> leerBloques(String nombreArchivo) throws IOException {
        List<String> bloques = new ArrayList<>();
        StringBuilder actual = new StringBuilder();

        File archivo = new File("sql", nombreArchivo);
        if (!archivo.exists()) {
            throw new IOException("No se encontró " + archivo.getPath() + ". Ejecuta el programa desde la carpeta del proyecto.");
        }

        BufferedReader lector = new BufferedReader(new InputStreamReader(new FileInputStream(archivo), StandardCharsets.UTF_8));
        try {
            String linea;
            while ((linea = lector.readLine()) != null) {
                if (linea.trim().equalsIgnoreCase("GO")) {
                    if (!actual.toString().isBlank()) {
                        bloques.add(actual.toString());
                    }
                    actual = new StringBuilder();
                } else {
                    actual.append(linea).append("\n");
                }
            }
        } finally {
            lector.close();
        }
        if (!actual.toString().isBlank()) {
            bloques.add(actual.toString());
        }
        return bloques;
    }
}
  • crearBaseSiNoExiste() se conecta al servidor (sin base, porque quizá aún no existe) y pregunta con DB_ID. Si da vacío, ejecuta CREATE DATABASE.
  • crearTablasSiNoExisten() pregunta con OBJECT_ID si existe la tabla carrera. Si no, ejecuta los dos scripts.
  • leerBloques() lee cada script de la carpeta sql y lo corta en cada línea GO, porque JDBC no entiende GO. Como busca la carpeta sql con una ruta relativa, el programa debe ejecutarse desde la carpeta del proyecto; los archivos .bat se encargan de eso.

@echo off

Paso 26Otras formas de ejecutar

Los dos comandos a mano

Es lo que hace ejecutar.bat. Desde la carpeta del proyecto:

javac -encoding UTF-8 -sourcepath src -d build\classes -cp lib\mssql-jdbc-12.8.1.jre11.jar src\uasd\catalogo\Main.java
java -cp "build\classes;lib\mssql-jdbc-12.8.1.jre11.jar" uasd.catalogo.Main

El primero compila y el segundo ejecuta. Si ejecutas desde otra carpeta, el programa no encontrará la carpeta sql para crear la base. Por eso conviene usar ejecutar.bat.

En NetBeans, como en los videos y el blog

El proyecto ya trae sus archivos de NetBeans (build.xml, manifest.mf y la carpeta nbproject), con el driver agregado, la clase principal marcada y la versión de Java en 11. Por eso no hay que configurar nada:

  1. File → Open Project, elige la carpeta catalogo-carreras-uasd y pulsa Open Project.
  2. Enciende SQL Server (paso 2) y pulsa el botón verde (Run).

Se probó en Apache NetBeans 31 con JDK 21. El proyecto compila para Java 11, así que sirve con cualquier JDK 11 o superior. NetBeans 8.2 trabaja con Java 8, y este proyecto necesita Java 11 o superior.

Crear el proyecto de NetBeans desde cero

Es lo que se hizo para generar esos archivos, y es lo que mostrarían los videos:

  1. File → New Project (Ctrl + Shift + N). En Categories elige Java with Ant y, a la derecha, Java Project with Existing Sources.
  2. En Name and Location, elige la carpeta del proyecto. Si ya existe una carpeta build dentro, NetBeans no deja continuar ("Cannot place the project in a project folder that already contains build folder"): bórrala, porque la vuelve a crear al compilar.
  3. En Existing Sources, agrega la carpeta src. Pulsa Finish.
  4. Clic derecho sobre Libraries, Add JAR/Folder... y elige lib\mssql-jdbc-12.8.1.jre11.jar. Si no haces este paso, el programa falla con "No se encontró el driver de SQL Server".
  5. Clic derecho sobre el proyecto, Properties → Run → Main Class, y elige uasd.catalogo.Main.
  6. Si tu JDK es más nuevo que el 11, en Properties → Sources pon Source/Binary Format en 11 para que el proyecto sirva en otras computadoras.

NetBeans ejecuta desde la carpeta del proyecto, que es lo que el programa necesita para encontrar la carpeta sql. NetBeans y compilar.bat usan la misma carpeta de salida (build\classes), así que no los uses a la vez.
