El programa en un minuto

Es una ventana con un selector de facultades de la UASD y un botón Consultar. Al pulsarlo, el programa pide a una base de datos SQL Server las carreras de esa facultad y las muestra en una tabla, con su escuela, nivel (Técnico o Grado) y estado (Vigente o Proyectada).

Los datos son reales: salen del Catálogo de Oferta Académica oficial de la UASD (9 facultades, 51 escuelas y 140 carreras de nivel Técnico y Grado).

SQL y T-SQL

SQL (Structured Query Language, lenguaje de consulta estructurado) es el lenguaje para hablar con una base de datos relacional. Sirve para definir las tablas (CREATE TABLE) y para pedir y guardar datos (SELECT, INSERT). Es declarativo: dices qué quieres y la base decide cómo encontrarlo.

T-SQL (Transact-SQL) es el dialecto de SQL de Microsoft, el que entiende SQL Server. Casi todo el SQL es igual en todas las bases (MySQL, PostgreSQL, Oracle), pero cada fabricante agrega cosas propias, como los distintos acentos de un mismo idioma. Lo propio de T-SQL que usa el proyecto:

N'Técnico'La N indica que ese texto es Unicode, es decir, con tildes

GOSepara bloques en un script. No es SQL real: lo entienden las herramientas de SQL Server, y por eso InicializadorBD corta el script en cada GO

TCP y el puerto 1433

TCP (Transmission Control Protocol) es la forma en que dos programas se hablan por red usando una dirección y un número de puerto. Es como una llamada telefónica: la dirección (localhost, que significa "esta misma computadora") es la casa a la que llamas, y el puerto (1433) es la extensión donde SQL Server contesta.

El driver JDBC solo sabe llamar por TCP. Por eso el blog de la clase pide habilitar TCP/IP en el SQL Server Configuration Manager y fijar el puerto 1433. LocalDB, la versión liviana de SQL Server que a veces viene instalada, no abre ese puerto y no sirve para este programa.

SQL Server Express: cómo se prepara

SQL Server Express es el servidor de base de datos, un programa que queda corriendo en segundo plano (un servicio de Windows llamado SQL Server (SQLEXPRESS)). Para que Java pueda hablar con él hay que dejarlo así, como pide el blog de la clase:

  1. Al instalarlo, elegir autenticación mixta (Mixed Mode) y ponerle una clave al usuario sa. El programa usa Catalogo_UASD_2026, que ya está en ConexionBD.java.
  2. En el SQL Server Configuration Manager, habilitar el protocolo TCP/IP.
  3. En las propiedades de TCP/IP, en IPAll, dejar vacío TCP Dynamic Ports y poner TCP Port en 1433.
  4. Reiniciar el servicio. Desde ese momento SQL Server atiende en localhost:1433 y el programa Java se conecta ahí.

Base de datos relacional en una idea

Los datos se guardan en tablas, como hojas de cálculo: cada fila es un registro (una carrera) y cada columna es un dato (su nombre, su nivel). Las tablas se relacionan entre sí por números: la tabla escuela guarda el id de su facultad, así que no repite el nombre de la facultad en cada fila. Para leer los datos se escribe una consulta en SQL.

Cómo se ejecuta el programa, y por qué con un comando

Por qué hace falta un comando

Un programa de Java no es un archivo .exe que se abre con doble clic. Lo que se escribe (.java) se compila a archivos .class, y esos los ejecuta la máquina virtual de Java (JVM). Para arrancar, a la máquina virtual hay que decirle tres cosas:

  1. Qué programa ejecutar: el nombre de la clase que tiene el método main.
  2. Dónde están tus clases compiladas (la carpeta build\classes).
  3. Dónde están las librerías que usa: el driver de SQL Server.

Un comando es la forma de decir esas tres cosas por escrito. Con doble clic, Windows no sabría qué clase arrancar ni dónde está el driver.

Analogía. Es como encender un carro. La llave (el comando) le dice al motor (la máquina virtual) que arranque, y con qué. Un IDE como NetBeans tiene un botón verde "Run" que arranca con botón: por dentro ejecuta ese mismo comando.

El método main

Cuando ejecutas una clase, la máquina virtual busca en ella un método con exactamente esta forma y lo llama. Es el punto de entrada: por ahí empieza todo.

Main.java:11
public static void main(String[] args) {
PalabraQué significa
publicLa máquina virtual, que está afuera de la clase, tiene que poder verlo
staticSe puede llamar sin crear antes un objeto. Es necesario porque al arrancar todavía no existe ningún objeto
voidNo devuelve nada
mainEl nombre fijo que la máquina virtual busca
String[] argsLa lista de datos que se escriben después del nombre de la clase en el comando. Este programa no los usa

Si una clase no tiene este método, al ejecutarla Java avisa que no encuentra main.

Los comandos

Compilar y ejecutar son dos comandos de Java. Los archivos compilar.bat y ejecutar.bat los resumen. Un .bat es un archivo de texto con comandos de Windows que se ejecutan uno tras otro. Desde la carpeta del proyecto, esto compila y abre el programa:

.\ejecutar.bat

Estos son los dos archivos:

compilar.bat

@echo off
cd /d "%~dp0"
if not exist build\classes mkdir build\classes
javac -encoding UTF-8 -sourcepath src -d build\classes -cp lib\mssql-jdbc-12.8.1.jre11.jar src\uasd\catalogo\Main.java

ejecutar.bat

@echo off
cd /d "%~dp0"
call "%~dp0compilar.bat"
if errorlevel 1 exit /b 1
java -cp "build\classes;lib\mssql-jdbc-12.8.1.jre11.jar" uasd.catalogo.Main

super(...) y @Override explicados

Son dos cosas distintas que aparecen en las clases hijas.

super(...)

super significa "mi clase padre". Con paréntesis, super(...) llama al constructor del padre. Cuando una hija crea un objeto, primero hay que construir la parte que viene del padre, y eso lo hace super(...). Debe ser la primera línea del constructor, y los datos que le pasas deben coincidir con los que pide el padre.

Esa línea le pasa los datos al constructor de Carrera, que los guarda. A su vez, Carrera usa super(id, nombre) para pasarle el id y el nombre a EntidadCatalogo. Es una cadena: CarreraTecnica → Carrera → EntidadCatalogo.

Analogía. Un hijo hereda la casa de su padre, pero la casa hay que construirla primero. super(...) es "construye primero la parte del padre con estos datos".

@Override

Significa "este método reemplaza o completa uno que viene del padre". Es un aviso para Java y para quien lee el código. Sirve para dos cosas: avisa que el método viene de arriba, y protege de errores de escritura. Si escribes getNiveel() por error, Java dice "este método no existe en el padre" y no compila.         return true;

El driver (JAR)

El JAR del driver

Un JAR es un archivo comprimido, parecido a un .zip, que contiene clases de Java ya compiladas. Es la forma de empaquetar una librería para usarla en otro programa. El driver de SQL Server es un JAR: mssql-jdbc-12.8.1.jre11.jar, de 1,4 MB. Dentro tiene las clases que saben hablar con SQL Server, entre ellas la que se carga con Class.forName.

Analogía. El JAR es un ingrediente de la receta: la harina. Tu código es la receta, y sin el ingrediente no sale el plato.

Cómo se consigue

El blog de la clase lo descarga desde la página de Microsoft. Es el mismo archivo, publicado también en un repositorio público de librerías de Java. Se puede bajar con un comando, que lo deja en la carpeta lib:

Invoke-WebRequest -Uri https://repo1.maven.org/maven2/com/microsoft/sqlserver/mssql-jdbc/12.8.1.jre11/mssql-jdbc-12.8.1.jre11.jar -OutFile lib\mssql-jdbc-12.8.1.jre11.jar
